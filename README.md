# 🍔 BiteCraft – Burger Shop POS System

 **Burger Shop Point of Sale (POS) System** built using HTML, CSS, and JavaScript.

BiteCraft helps manage burger shop operations efficiently, including product management, customer management, order processing, shopping cart functionality, and sales reports.

🌐 **Live Demo:** [BiteCraft Burger Shop POS](https://bitecraft-burger-shop-system.vercel.app/)

📂 **GitHub Repository:** [BiteCraft – Burger Shop POS System](https://github.com/Roneth87/BiteCraft-Burger-Shop-POS-System)


## ✨ Features

### 🛒 Point of Sale (POS)
- Display available food products.
- Add products to the shopping cart.
- Increase and decrease product quantities.
- Automatically calculate total prices.
- Remove products from the cart.
- Clear the entire cart.
- Place customer orders.
- Add new products to the shop.

### 🍔 Product Management
- Add new products.
- View all products.
- Edit existing product details.
- Delete products.
- Manage product categories and prices.

### 👥 Customer Management
- Add new customers.
- View customer details.
- Edit customer information.
- Delete customer records.

### 📦 Order Management
- Place new orders.
- Store customer order details.
- Calculate order totals automatically.
- View order history.
- Delete orders.

### 📊 Reports & Dashboard
- View total revenue.
- Display total orders.
- View order details.
- Generate sales summaries.

### 💾 Data Storage
- Store application data using Browser Local Storage.
- Maintain data after page refresh.
